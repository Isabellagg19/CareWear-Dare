# CareWear-Dare
Welcome to the WearCare Dare website, this is not just another website, this is a 4 weeks long habit changing challenge.
Right now we are facing one of the biggest enviormental crisis in history, grat part due to big world industries such as the fashion industry, and as the future of the world it is our responsability to face it, if we want to have a beutiful future, this challenge is meant to show young people that is possible being part of the solution, and it is actually a lot easier than what society usually tell us.
I design it using html, css and js, to create 4 interactive and fun dares, each one for a different week and I used colors releated to fashion and beauty to give it a special touch.

I hope you enjoy it and that it help us all to buy clothes more consciusly
